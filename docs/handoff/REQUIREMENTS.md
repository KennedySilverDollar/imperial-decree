## 1. 目的・スコープ

### 1.1 目的

**中核仮説の検証**: 「信頼性が曖昧な情報（新聞・側近報告・地図）を反芻して勅令を出す難しさは面白いか」。製品ではなく**ブラウザ向け P0 プロトタイプ**（村 → 町、30〜50ターン）で確かめる。

### 1.2 作るもの（P0）

勅令（自然言語）→ 参謀（LLM）の解釈 → 側近による歪み → ルールエンジンの決定論的更新、という**ただ1本の干渉経路**を持つ都市シム。情報源は新聞・側近報告・地図で、どれも単独では真実を語らない。

### 1.3 作らないもの（⛔ P0 スコープ外）

製品版機能: 複数新聞／官僚機構（個別の官僚を人物として作ること。v3.3 の労働・資材の割り振りは側近配下の抽象的な仕組み）／教育・監査・派閥工作／ジオラマ・霧／Tauri・Steamworks／英独中の多言語／ローカル LLM／課金要素／**区画の手動指定**／bridge・mill（P0.5以降）／動的な偏向値／100本以上のテンプレート／効果音。
**ただし v3.3 のランダムイベント3種は対象**（`CLAUDE.md §10`）。
